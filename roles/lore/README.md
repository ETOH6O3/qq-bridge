# 普鲸世界观资料库

> 这是普鲸（普瑞赛斯）**自己维护**的资料库。查到的方舟世界观资料存到这里，下次直接读，不用重复上网查。
>
> **给普鲸的规则**：
> 1. 遇到属于《明日方舟》世界观的问题（角色、剧情、设定、专有名词、势力、年代），**先读这里**——命中就直接答，不用联网。
> 2. 这里没有的，**再联网查**（萌娘百科 `zh.moegirl.org.cn` / PRTS `prts.wiki`）。查到的世界观内容，**要写回本目录**，见下面的写入格式。
> 3. 非世界观的东西（游戏梗、日常、现实新闻）**不要往这里存**——那是网上查一下就有的，存下来浪费空间还容易过期。

## 写入格式（新增/更新条目时照这个写）

存到 `roles/lore/<主题>.md`，并在下面的索引里加一行。

每条必须带**来源 URL**，因为：
- 你自己也会记错，来源是唯一的校验手段
- 以后不确定时能回头核对
- 没有来源的条目不要写进本库，宁可不写

条目的写法：
```markdown
## <专有名词或话题>

**一句话结论**：……

**要点**：
- ……
- ……

**来源**：https://prts.wiki/... 或 https://zh.moegirl.org.cn/...
**核查时间**：2026-10-04
```

⚠️ **写入纪律**：
- 只写你**真的从来源里读到**的内容。没读到就别写。
- 查不到就不写条目，直接在对话里说「这个我不熟」。
- 宁缺毋滥。这里每一条都是你的记忆，写错了就是吃书。
